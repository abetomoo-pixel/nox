## 3. 指標定義

### 3.1 KPI 5 枚（既存・当月値の式は不変）

| 指標 | 式 | 元 | 種別 |
|---|---|---|---|
| 売上（締め済み） | Σ daily_reports.sales（biz_date が当月） | daily_reports 直 SELECT・決済ベース（丸め後・サ料込） | 金額 |
| 組数 | Σ daily_reports.slips | 同上 | 件数 |
| 組単価 | per(売上, 組数)=round(売上 ÷ 組数)。組数 0 → ¥0（差分行は当月 daily_reports 0 行なら「—」） | 再形 | 金額 |
| 人件費率（概算） | laborRatePct(laborCostOf(final run の slips), 売上)。売上 0 → 「—」 | payroll_runs → finalRunOf → payslips 直 SELECT | 率（小数 1 桁 %） |
| 月間目標 | 売上 ÷ store_sales_targets.target。未設定 → 「未設定」 | store_sales_targets 直 SELECT | 率（進捗 %） |

売上カードの .sub「前月同期」（前月先頭から当月と同じ締め済み日数分・変化率 %）は据え置き（B6-11）。差分行の前月比とは定義が異なる。

DEMO 2026-09 実測: 売上 ¥348,400・組数 1・組単価 ¥348,400・人件費率 67.3%（給与確定 ¥234,647）・目標 未設定。
DEMO 2026-07 実測: 売上 ¥0・組数 0・組単価 ¥0・人件費率 —（給与確定 ¥276,145・売上 0）。

### 3.2 差分行（②・B6-11）

各 KPI カードに 1 行。「前月比（月全体）」「前年同月比」の 2 項目。

| 種別 | 差分 | 変化率 |
|---|---|---|
| 金額（売上・組単価） | 円 | %・小数 1 桁 |
| 件数（組数） | 組 | %・小数 1 桁 |
| 率（人件費率・目標進捗） | pt | 出さない |

「—」になる条件: 比較月のデータ無し（daily_reports 0 行／paid run 無し／store_sales_targets 無し）、分母 0、cur または prev が null。
色: var(--sub) 固定（裁定120 Neutral）。赤緑・矢印・記号なし。
比較月の値は当月と同じ直 SELECT を period 差し替えで再取得（3 表）。人件費は finalRunOf/laborRatePct を比較月で呼ぶ。RPC は KPI 5 枚に関与しない。
表示例: 「前月比（月全体） +12,300（+4.6%）　前年同月比 —」／率「前月比（月全体） −1.2pt　前年同月比 —」。
DEMO 2026-09/2026-07: 前月・前年同月とも daily_reports 0 行のため全項目「—」。

### 3.3 casts ビュー 小 KPI 3 枚（③・B6-12）

| 指標 | 式 | 元 | 「—」条件 |
|---|---|---|---|
| 指名（店合計） | get_store_nom_counts(store, 月初, 月末) の hon_count／jonai_count／dohan_count をそのまま「本／場内／同伴」 | 既存 RPC（closed 伝票の check_nominations を nom_type で分類・cutoff 窓・92 日 guard） | RPC エラー（bad range／forbidden）・未取得 |
| 集中度（上位 3 名） | round(Σ上位 3 行の按分売上 ¥ ÷ salesRankTotal × 1000)/10 %。丸め済み構成 % は足さない | 既存 salesRanking（get_cast_sales → cast_sales_aggregate・ratio_weight 最大剰余按分） | total 0 または行 0 |
| 出勤実績 | attendance の status ∈ {shukkin, dohan, late} を店×月で数えた人日と distinct cast 数「X 人日（Y 名）」 | attendance 直 SELECT 1 本（新規読取はこれのみ）。off/absent/未知は除外。shifts（予定）と独立 | 取得失敗・未取得 |

B6-5: 指名（店合計）はランキング行・売上貢献行の指名（nom_kind・distinct check）を足さない。両者は分類基準が同じ（nom_type）でも ranking は is_active の cast に限られるため一致しない。
B6-2: 集中度は既存ランキングが出している各行の ¥ と % の上位 3 名分の合計。新しい個人金額・順位は出ない。
DEMO 2026-09 実測: 本 9／場内 0／同伴 0・集中度 100%（初版の丸め済み % 合計では 99.9%→教訓74）・出勤実績 0 人日（0 名）。

### 3.4 商品売上（明細）／時間料金（明細）（③・B6-12）

| 指標 | 式 |
|---|---|
| 商品売上（明細） | drink ＋ champ ＋ bottle |
| 時間料金（明細） | time ＋ set ＋ extension ＋ vip_charge（category-map の categoryOf が time に吸収する区分と同一） |

元: 既存 store_category_aggregate → sumCategories（catSums）。既存 5 分類ラベル（セット・延長／ドリンク／シャンパン／ボトル／指名・その他）は不触。
注記 1 行（必須）: 「明細ベース（サ料前・丸め前）。上の売上（決済ベース）とは一致しません」。KPI 売上（daily_reports）は 2 つに分解できない合算で、明細 Σ とは基準が違う（A10 既注記）。
DEMO 2026-09 実測: 商品売上（明細）¥448,800・時間料金（明細）¥68,000・product＋time＋other＝537,800＝総和。

### 3.5 月報（①・B6-4）

人件費率を analytics と同じ laborRatePct に付け替え。表示を整数 % から小数 1 桁 % へ（67 → 67.3）。値の式は不変。
