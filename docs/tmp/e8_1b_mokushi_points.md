## F1 人数単位（person 制）

1. マスタ → 料金設定 → 時間料金設定: 単位セグが「卓単位｜人数単位」表記＋下に説明文
   （卓単位＝1伝票につき…／人数単位＝伝票の人数×料金…人数変更に自動で追随）。
2. **CLUB NOX は人数単位に恒久切替済み**（ご指示どおり）。
3. レジで開卓（人数2）→ 会計タブ: セット料金行が **「¥5,000 × 2名 ¥10,000」** の形（×N名 表記）。
4. 伝票ヘッダの人数±を 2→3 に変更 → 会計タブ再入場でセット行が ×3名 に追随。

## F2 指名フロー1本化

1. 伝票 → 指名・席タブ: nom_type プルダウンが消え、**本指名｜場内｜同伴｜フリーのセグ**に。
2. キャスト選択は CastPicker（検索＋写真グリッド）。選ぶと按分の重みにも同時反映。
3. 「本指名料を付ける（＋按分）」を押す → 明細に指名料行＋
   **「れいな に本指名料 ¥3,000 を追加し、按分にも反映しました」** の成功メッセージ（緑）。
   ¥0 だった場合は ¥0 警告が出る（旧: 無言で ¥0 行が積まれるバグ→是正済み）。
4. 按分の重み微調整は **「按分の重みを微調整（れいな＝100%）」の折りたたみ**の中＋「按分を保存」。

## F3 席操作の視覚化

1. 指名・席タブの席カード: ボタン2つ「相席を追加」「席を移動」。
2. どちらを押しても **空席タイルのグリッドモーダル**が開き、タイルをタップで確定（旧 select 廃止）。

## F4 ナビゲーション

1. 伝票詳細を開いた状態でサイドバー「レジ」を再クリック → **フロア（卓一覧）へ戻る**。
2. 「← フロア」ボタンが大型化（太字 15px・押しやすいサイズ）。

## F5 会計グループ付け替え（mig0091）

1. 会計タブの明細行: グループバッジが **「会計A ▾」ボタン**に。タップでモーダル。
2. モーダルで「会計B」を選ぶ → 行が会計Bへ移動しバッジ表示が追随（合計は不変）。
3. 「＋会計を分けてそこへ」で新グループ作成と同時移動。
4. 動かせない行（自動時間料金・割引行・入金済みグループ・close 済み）はバッジが淡色で反応しない。
   ※自動時間料金行は DB 側でも 'time line' で拒否（会計A固定）。

## F6 会計完了モーダル＋簡易領収書

1. 入金 → 会計完了（close）→ **「会計完了」モーダル**: 合計・お釣り（最後の現金入金の釣銭）。
2. 簡易領収書: 宛名（空欄可）＋但し書き（既定「お飲食代として」）→「領収書を印刷 / PDF」で
   ブラウザ印刷（白地黒字・宛名/金額/但し/日付/店名）。画面には印字内容は出ない（印刷時のみ）。
3. レシート再印刷ボタンは**プリンタ設定オンの店のみ**表示（CLUB NOX は未設定のため非表示＝仕様）。
4. 分割領収書・QR・採番は後送りのまま（E8-1b 指示どおり）。

## E8-1c 分割領収書＋人数注記

1. close 後モーダルの簡易領収書が**分割ダイアログ**に: 「1〜10枚に分割できます。均等割り
   （最後の1枚は残額を自動計算）＝発行合計は会計金額と必ず一致します」の説明＋枚数ボタン 1〜10枚。
2. 3枚を選ぶ→均等割り（例 ¥2,200 → 734/733/733）。最終枚は readonly＋「残額を自動計算」表記。
3. 1枚目の金額を手修正（例 1000）→最終枚が残額へ自動再計算（例 467）・
   下部に「3枚・合計 ¥2,200（会計金額と一致）」。不一致になる操作は構造上できない
   （万一 0 円以下になる編集はクランプ・印刷ボタンは一致時のみ有効）。
4. 宛名・但し書きは**枚数分 個別入力**（空欄＝上様／ご飲食代として）。
5. 「領収書を印刷 / PDF（N枚）」→ブラウザ印刷で**1枚=1ページ**（page-break）・各枚に宛名/金額/但し/日付/店名。
6. 発行番号・QR のボタンは**出ない**（R2 送りのまま）。
7. 伝票ヘッダの人数±の下に注記（person 制の店のみ表示・モード別の正確な文言）:
   - 自動店:「※セット中の人数変更はセット料金に反映されます。延長中の変更は現在は
     全時間に反映されます（延長時点からの加算は今後の改修で対応）」
   - 手動店:「※セット中の人数変更はセット料金に反映されます。追加済みの延長行には
     反映されません（延長は追加時点の人数で確定します）」
   ※卓単位の店は人数が料金に効かないため注記を出しません（嘘をつかない）。
