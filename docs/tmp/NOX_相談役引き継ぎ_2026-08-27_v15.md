## 10. 恒久注意（毎回効く）

- **dev 起動中に verify / build を回さない**（教訓36）。回復は `Get-NetTCPConnection -LocalPort 3200` → 停止 → `Remove-Item -Recurse -Force .next`
- **verify は2回連続で緑を要求する**。1回目緑・2回目赤は蓄積由来の時限装置（教訓35）
- **新しい assert には必ず逆張り検証**（赤→戻して緑）。緑だけでは受理しない
- **`setDayModal(` の開く口/閉じる口は内訳まで出す**（教訓33）
- **CC への指示は `/` で始めない**。全ブロックに「複雑な作業と判断したら着手前に申告して停止すること」を入れる
- **コミットは単一 `-m`・co-author なし・push は phase 完了時のみ**
- **money 三面鏡**（RPC / check-calc.ts / receipt）は同時に変える。golden 6値は不変がゲート
- **Fable 5 を使う判断**：RLS/権限変更、大規模設計、money 隣接、golden が動く変更
- ★**語の一致で仕分けしない**（教訓40）＝モック照合は生成コード（renderX）の出力まで読む。
