## 2. 今の作りの差（まとめ）

1. **段（pay_rate_tiers）を入れる画面が無い**。書く RPC（comp_plan_ext_set・owner）は本番にあり、段（at_pct・up_amount・down_amount・back_mult・pay_pct・wage_cut_pct・hon_back_rate・days_min・back_gate_pct・bonus_pct＝10 段まで）も受け付ける＝画面を作るなら mig は不要。履歴にも画面の跡は無い（デモの種だけが書く）。
2. 連続 N 期（slide_streak_n）・入店後の猶予（assess_grace_months）・バックの単位（hon／jonai／dohan_back_unit・hourly_add）・席種別の商品バック・同伴の時間帯（plan_rate_bands）・W 別規定（plan_norm_tiers）・給率帯のバック率（back_rate_tiers）も、画面が無い（RPC は comp_plan_ext_set か専用の表）。
3. 初期設定の「報酬率スライド」は選べるが保存しない（段の形が「率 → 時給」で、計算の「率の段 → 来期の上げ幅」と合わない）。
4. CLUB G 型（給率で時給を減らす）は、⑫ の差し替え（査定は時給を変えず支給率で総報酬に掛ける）で表せない。表すには ⑫ を店ごとに選べるようにする判断が要る。
5. 店舗設定の「報酬の軸」は売上／ポイントの 2 つ（報酬率はプランごとだけ）。

## 3. 判断が要るもの（朝の報告 ⑥-1 と同じ）
- 段の画面を作るか（作るなら mig 不要・owner だけ・10 段・昇順の検査は RPC と同じ）。
- 初期設定の段の形を計算の形に揃えるか。
- CLUB G 型（時給を減らす査定）を入れるか（⑫ の差し替えとの関係）。
