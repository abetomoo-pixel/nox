## ★E3 へ持ち越す気付き（E1 のスコープ外・記録のみ）

`theme.ts` の**部品プリミティブ内リテラル**は E1 で触っていない（トークンではないため）。
そのうち以下は「旧 `--bg` の値 `#0B0B0F`」をベタ書きしており、新 `--bg`（`#080808`）と 3 単位ずれる。
視認できない差だが、**E3（部品）で解消すべき drift**として記録する。

| 箇所 | リテラル | 備考 |
|---|---|---|
| `rolePill.color` | `#0B0B0F` | 旧 `--bg`。モックの `.btn.primary` は `#17130c` |
| `btnGold.color` | `#0B0B0F` | 同上（実測: /login の主ボタン文字が `rgb(11,11,15)`） |
| `slipFoot.color` | `#0B0B0F` | 同上 |
| `btnGold` / `rolePill` / `slipFoot` の背景 | `#B8893A`（gold の暗色） | モックは `#b48634`／`#b68835` |
| `avatarBg` の生成色 | HSL 計算 | 名前ハッシュ由来＝トークン非依存（意図どおり・変更不要） |
| `appBg` / `loginBg` のグラデ始点 | `#15131C` / `#1A1622` | 紫寄りの旧トーン。モックは金グロー（`radial-gradient(…gold .1…)`）＝E2 の地の設定で再検討 |
