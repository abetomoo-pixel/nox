## 1. 表(新規3+店舗設定1)

### 1.1 staff_shift_patterns(枠)
| 列 | 型 | 備考 |
|---|---|---|
| id | uuid pk | |
| org_id / store_id | not null | 店舗単位 |
| name | text not null | 「早番」等 |
| start_hm / end_hm | text not null | HH:MM・30時間制・既存 shifts と同一 CHECK(C②-5) |

規則: 過去日禁止・未来行のみ削除可・「営業日 D に有効な枠」=同名で effective_from ≤ D の最大行(横断 §1 解決)。

### 1.3 staff_shifts(確定行)
| 列 | 型 | 備考 |
|---|---|---|
| id | uuid pk | |

### 1.4 店舗設定: 締切
`stores.settings_json` には置かない(横断 §4 の流儀=設定と機能公開を混ぜない・既存3キーのみ)。新表 `staff_shift_deadlines`(store_id × days_before int × deadline_hm text HH:MM × effective_from・unique(store_id, effective_from))。無ければ既定=3日前 21:00(定数・code 側)。cast 側の締切(date のみ)は触らない(C②-8)。

## 2. RPC(すべて SECURITY DEFINER・null-guard 先頭・`flag_enabled('staff_shift')` false → `raise 'feature_disabled:staff_shift'`(C②-10))

| RPC | 権限 | 概要 |
|---|---|---|
| staff_pattern_set | owner/manager 自店 | 枠の作成(effective_from ≥ 営業日)。同名同日は unique 違反 |
| staff_pattern_delete | 同上 | 未来行のみ |
| staff_wish_set | 黒服本人 | 締切前のみ。◯×と note。締切判定は当日有効な deadlines 行 |
| staff_shift_propose | manager 以上 | 希望から行を作成(時刻を枠から写す)。または希望なしで直接作成 |
| staff_shift_override | manager 以上 | start_hm/end_hm 上書き(confirmed 後も可)。audit action=`staff_shift_override` |
| staff_shift_confirm | manager 以上 | 行を confirmed。営業日単位の一括は client が行ごとに呼ぶ(RPC は行単位) |
| staff_deadline_set | owner/manager | deadlines 行の作成(effective_from 型) |

監査: 6 RPC すべて RPC 名を action として audit_log_write へ(C②-11・reason は任意)。
解除(confirmed → proposed)は本書に**含めない**=C層③ reopen_flow の対象(横断 §5)。C層② では「confirmed 行の時刻上書き」までで、status は戻さない。

## 3. RLS・ACL(横断 §4 ACL 流儀)

- 4表とも `revoke all from public, anon, authenticated` → `grant select to authenticated`。書込は RPC のみ
- select policy: owner/manager=自店全行・黒服=自分の行(patterns/deadlines は自店全行)・cast=不可(黒服シフトは cast に見せない)
- 黒服本人=`auth_membership_id()`(新設・C②-9)。owner/manager 自店判定は既存ヘルパー(§8 実測の実名)

## 4. UI(flag off=導線ごと出さない・横断 §4)

- 店舗設定(owner/manager): 枠の一覧(現在有効+予約・過去は折りたたみ)・「◯日から」1入力・締切設定
- 黒服(本人): 月カレンダー×枠の ◯× タップ・締切後はロック表示・note 1行
- manager: 営業日ごとに「枠×充足(2/3)」・希望一覧から propose・行の時刻上書き・営業日一括確定
- 表示: 行の時刻が枠と違えば「9:00〜11:00(枠 12:00)」
- 導線: /shift の現行 5 タブ(today/queue/build/calendar/roster)の左に対象切替(キャスト/黒服・モック v4.1 H3)。flag off で切替不在
