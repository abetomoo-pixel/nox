## §4 3原則の UI 表現（確定）

**a. 時間だけのルール禁止**
- 入力制御は現行の帯編集検証（金額必須）が充足。
- ルールタブ冒頭 lead＝「時間だけのルールは作れません——各行が時間帯・条件・金額・基準時間をひとまとめに持ちます」（v3 逐語）。
- 帯編集モーダル hint＝「時間帯だけを先に作ることはできません（料金とセットで保存します）」。

**b. 時間課金の確定＝開栓時固定（選択制にしない）**
- A1 カードに固定 pill（入力にしない）＝「時間課金の確定: 伝票オープン時（固定）」。
- 注記＝「料率は伝票を開いた時刻のルールで確定し、以後の設定変更・席移動・日付跨ぎでは変わりません（延長も開栓時の料率で加算）」。

**c. 区分も開栓凍結**
- 開卓モーダルのセレクタ hint＝「区分は開栓時に確定します。あとから変更はできません（変更は会計取消→再開卓）」。
- 伝票ヘッダは凍結値 category_name を表示。区分カード注記「無効化しても過去の伝票には影響しません」据え置き。
