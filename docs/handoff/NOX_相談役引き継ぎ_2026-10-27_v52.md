## 6. 教訓・運用（v51 §6 に加える）

- **教訓122**: 主ボタン中央は f0 で機械判定する・live に毎便「主ボタン中央」を含める。
- **f0 の actions-center は dev（3200）に依存**＝ファイルの削除・大きな置換の後は dev を再起動してから f0（QR 便の run1 で 500）。走査の間だけ NOX-VERIFY の規約同意の行を足して消す（残留 0 を確認）。
- **search_path は `'public', 'extensions'`（リスト）で書く**＝`'public, extensions'`（1 つの名前）だと pgcrypto が見つからない（0175 ★27 の 4 本＝本番で失敗）。生成器の新設関数も同じ。
- **f0 を 0:00〜06:00 に走らせると営業日と暦日がずれる**＝staff-shift の「当日 23:59 の締め切り」が過ぎた扱い（締め切りの上限は営業日の 23:59）→その時間帯だけ翌営業日で確かめるよう suite を直した（OB 便）。ほかの suite でも深夜の赤は時計を先に疑う。
- **夜間に f0 を続けて回すと Supabase の認証の回数上限・API の 502 に当たる**（10/27 02 時台に 4 回）＝赤の前に API の状態を見る・掃除の失敗で残った NOX-VERIFY の行は参照 0 を確かめて消す。
- 同一 tx の now() で in と out が同時刻＝順序が不定（教訓98 の型）＝suite で 1 秒ずらす（daily-pay）。
