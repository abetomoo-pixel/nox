## 6. 教訓・運用（v56 §6 に加える）
- **教訓 132（11/04 相談役採番・確定）**＝mig の begin; の直後に `set local lock_timeout = '10s';` を入れる。根拠＝0193 の 1 回目が deadlock（表の ALTER＝ポリシー・列・CHECK と、稼働中の関数の CREATE OR REPLACE を 1 本で流すと、営業中の読み書きとロックの順が交差する）。lock_timeout なら待ち続けずに失敗し、単一トランザクションで無傷のまま貼り直せる。0194 の生成器から既定で入れる（相談役採番）。
- f0 の終了の印は cmd の `&& echo F0_OK || echo F0_NG`（`& echo %ERRORLEVEL%` は展開が先で常に 0＝無意味）。
- bash に gh が無い＝Vercel の反映は本番の chunk に新しい文字列があるかで確かめる（または live_wait_build.mjs に push 前の指紋を渡す）。
- pin の洗い出しは f0 ではなく run_suites.mjs（全 suite を 1 本ずつ・赤だけ記録）で先に回すと、1 回で全部の赤が見える（本便は 164 本＝13 本赤）。
