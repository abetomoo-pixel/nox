## よくある質問（全文）
今の /lp の FAQ の 5 問から、今も本当の物だけ。問いは 5 問とも今の /lp のまま。答えで直した所は 2 か所（★）。

1. デモの利用に登録は必要ですか？
   - 不要です。店舗と立場を選び、デモ利用の規約に同意するだけで体験できます。
   - ★今の /lp は「利用規約に同意」。デモの画面の見出しは「デモ利用の規約」＝店舗向けの利用規約（/terms・弁護士の確認の前）と取り違えないように言い換えた。
2. どの端末で使えますか？
   - 店側はPC・iPad、キャストはスマホのブラウザで利用できます。レジはiPadでの利用を想定しています。（今の /lp のまま）
3. 導入はどのように進めますか？
   - 招待メールからパスワードを設定し、9ステップの初期設定へ。業態に応じた席・料金・メニュー・待遇の初期値を、自店に合わせて調整します。途中からの再開も可能です。（今の /lp のまま・9 ステップは lib/nox/setup/v5.ts の V5_STEPS の 9 個と一致）
4. 雇用と業務委託が混在していても使えますか？
   - キャストごとに契約区分を記録し、源泉のプレビュー・控除日数を明細に表示します。同じ店で両方を扱えます。
   - NOXは契約区分を記録するもので、労働者性や所得区分を判定するものではありません。源泉徴収の扱いは税理士などの専門家にご確認ください。
   - ★今の /lp は「キャストごとに契約区分と精算方式を記録し」。精算方式は今は店ごとの設定（店舗設定 › 給与・裁定507）＝「と精算方式」を外した。
5. 料金はいくらですか？
   - 月額29,800円／店舗（税込）です。年払いの割引もあります。詳細はお問い合わせください。（今の /lp の文のまま・1 文字も変えない＝検査 (5-2)）

入れていない物：立場（4 役）の説明・開発中の機能・利用規約へのリンク・公開デモの 7 店のカード（検査 (5-3) が見張る）。作った数字は無い。
