## 5. 恒久注意（本セッションで実証・追加分）

1. **教訓50**: RPC の入力検証を緩める mig は同列のテーブル CHECK・NOT NULL・trigger を同 mig で必ず見る（0123 の器抜け＝バンドル緑でも insert で constraint violation）
2. **検証バンドルの like パターンは自分のコメントに一致させない**（0121 ord3 が撤去理由コメントの「free は均等」を自己検出した事故）。撤去確認は撤去した**コード断片**で書く
3. **手貼りファイルは即 Downloads へ**。0123 で配置忘れ→CC が正しく「底本なし」停止。相談役は sha256・bytes・先頭コメントを毎回添える
4. 番号衝突: Downloads に BANZEN の `mig0123_*`（7月）が居た。CC は先頭コメント「mig NNNN NOX」で識別＝流入は無視（恒久注意8 の同型）
5. 並行 CC セッション禁止: 同一 working tree に2本立つと git 状態が信用できない。起動ブロックの期待値不一致＝まず「別セッションが進めた」を疑う
6. UI 完了3点セット（verify 緑＋CC 実機/console 0＋Agoora 実機）は不変。今日の push 14本は実機追認になった＝本来はゲート先行
