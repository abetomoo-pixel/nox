## 2. 表 `feature_flags`

| 列 | 型 | 制約 |
|---|---|---|
| id | uuid | pk default gen_random_uuid() |
| org_id | uuid | not null fk orgs |
| store_id | uuid | null=org 既定 / fk stores |
| key | text | not null・check key in ('staff_shift','reopen_flow','qr_order','notify') |
| enabled | boolean | not null default false |
| updated_at | timestamptz | not null default now()(更新は RPC 内で明示) |
| updated_by | uuid | null |

- unique: `(org_id, key) where store_id is null` / `(org_id, store_id, key) where store_id is not null`(部分 unique 2本)
- 整合 check: store_id が非 null なら stores.org_id = org_id(トリガでなく RPC 内検証)
- RLS: select は同 org の authenticated(`org_id = auth_org_id()`)。insert/update/delete は policy なし(RPC のみ)
- ACL: `revoke all on feature_flags from public, anon, authenticated; grant select to authenticated`
- 初期行: なし(行なし=false=fail-closed)。seed は入れない

## 3. 関数

### 3.1 `flag_enabled(p_key text, p_store_id uuid default null) returns boolean`
- SECURITY DEFINER・`set search_path = public`・null-guard(p_key null → false)
- 解決: 店舗行(p_store_id 指定時)→ org 行 → false
- org は `auth_org_id()`。p_store_id は同 org 検証(違えば false・raise しない=読取関数)
- STABLE・grant execute to authenticated。UI と C層②③ RPC の双方から呼ぶ(RPC 側は off なら raise 'feature_disabled:<key>')

### 3.2 `flag_set(p_key text, p_store_id uuid, p_enabled boolean, p_reason text default null) returns void`
- SECURITY DEFINER・null-guard(p_key/p_enabled null → raise)
- 権限: `auth_role() = 'owner'` のみ(manager 不可)。fail-closed
- key は check 制約に委ねず関数内でも whitelist 検証(raise 'unknown_key')
- upsert(org/store/key)。before/after を `audit_log_write('flag_toggle', target='feature_flags:<key>[:<store_id>]', before, after, p_store_id, p_reason)`
- grant execute to authenticated(内部で owner 判定)

### 3.3 `audit_log_write` 改変(#62)
- `audit_logs` に `reason text null` 追加
- `audit_log_write(p_action, p_target, p_before, p_after, p_store_id, p_reason text default null)`=既存5引数呼出は無変更
- `audit_log_write_service` も同様に末尾 `p_reason` 追加
- 引数追加=同名で pronargs が変わる → 旧 signature を `drop function ... (旧引数)` してから create(0134 の型)。呼出 141 本は位置引数・名前呼び 0(突合)=後方互換
- 名簿(docs/NOX_課金ゲート対象_v1.md): `flag_set`→A8 店設定 13→14 / `flag_enabled`→B(f) 読取 43→44。対象 114・除外 102・全数 216。billing 47-1 の pin 更新
