## §1 前提事実(2026-09-04 実測・設計の拘束条件)

1. **同一ドリンク行の二重は現行仕様**: claim 済み行でも close 按分は不変(drink_back=400 ∧ claim=400・対照同値・check_close prosrc に drink_claims 参照ゼロ)。113 はこれを変えない

## §2 器(DDL 設計)

### comp_plans へ3列追加(mig0086 の mode/rate pair 流儀を踏襲)

- `product_back_mode text not null default 'product_rule'` CHECK in ('product_rule','plan_rate','plan_fixed')
- `product_back_rate int` CHECK (0..100)・pair CHECK: mode='plan_rate' ⟺ rate not null
- `product_back_fixed int` CHECK (>=0)・pair CHECK: mode='plan_fixed' ⟺ fixed not null

既存全行は default 'product_rule' で無変更=⑥成立。

### check_cast_backs へ3列追加(恒久注意 snap 後方互換: nullable+読み手フォールバック)

- `source_mode text` null CHECK in 3値。**null=旧行=product_rule 扱い**(読み手フォールバック)
- `product_sales_base int` null CHECK (>=0) — plan_rate の按分売上母数の凍結
- `calculated_back_amount int` null CHECK (>=0) — plan_rate の算出額の凍結

nullable+CHECK のため既存行スキャンは自明通過。「基本料金」型の誤表示経路を作らない原則を遵守。

## §3 check_close の分岐(執行点=③)

1. **plan 解決(⑤)**: 伝票営業日時点で有効な cast_plan 行から plan を引く(単一日判定。C3 の期間3段選択とは別物=collect 無改修)。plan なし/解決不能 → product_rule 扱い(既定フォールバック)
2. **product_rule**: 現行按分そのまま+source_mode='product_rule' を記録(挙動差ゼロ)
3. **plan_rate**: 商品3列(drink/champ/bottle)=0 凍結。back_snapshot 按分と**同腕**(同一行集合・同一 weight)で行の売上額を按分 → product_sales_base へ凍結 → calculated_back_amount=母数×rate の丸め結果を凍結。kind 射程=drink/champ/bottle の3種(現行 productBack と同射程)
4. **plan_fixed**: 商品3列=0 凍結・base/calculated=null・source_mode='plan_fixed' のみ記録(金額化は payOf 側=§4)
5. **drink_claims には一切触れない**(裁定4)
6. 丸め流儀: 既存 rate 系(payOf の per-count/rate・0130 h 系)の丸めと同一にする。**起草直前 live 再 dump 時に CC 読み取りで現行流儀を確定**し mig に写す(新流儀を発明しない)

## §4 collect / payOf(給与側=方式判定を持ち込まない)

- collect: check_cast_backs の新3列も読み Σ。productBack 3種は現行どおり Σ(plan_rate/fixed 行は 0 なので自動整合)
- payOf: grossBase へ +calculatedBackΣ(plan_rate 分=凍結値の単純Σ)+productBackFixed(plan_fixed=plan 列参照の期間固定額・加算1点)
- 方式判定が給与側に入るのは plan_fixed の加算1点のみ(期間固定の性質上 close で凍結不能なため)。guarantee(床=max)・achievement(加算)との関係は grossBase 加算のため既存構造と自然整合
- sim: SimInput へ商品売上内訳(drink/champ/bottle 別)+3択分岐入力を拡張(裁定106 の器なし新規要素を同時消化)。payOf 共有原則(二重実装なし)を維持
