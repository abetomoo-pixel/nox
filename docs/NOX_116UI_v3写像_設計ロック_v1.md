- **D5: 会計設定タブへ両方集約**=税設定3値・サービス料・丸め+stores 基本料金

## 2. 開栓モーダル 区分セレクタ(116-UI 本体)

- 店の active 区分 0件 → セレクタ非表示・p_category_id 無送信=現行完全同値

- check_open は named-args へ p_category_id を追加送信。kiosk は本レーン対象外
  (無送信互換は mig0128 で担保済み)
- 既存 open 卓の再タップ=区分不問で冪等返却(mig0128 仕様・UI 注記不要)
- 伝票ヘッダへ凍結値 category_name を表示(checks.category_name・null は非表示)

## 3. ルール編集の区分割当
