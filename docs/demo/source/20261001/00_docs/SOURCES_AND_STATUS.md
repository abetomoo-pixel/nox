# 出典・採用方針

出典は、この会話で提示された架空のデモ設定案と、ユーザー提供のNOX設定画面です。
外部の店舗価格、実際の仕入相場、現行の法令要件を調査して作ったデータではありません。
店舗名・顧客名・人物名はデモ識別用です。実在人物や実店舗の実績を示しません。

商品は最後の「6店舗分の商品マスター」の一覧を採用しました。
原価追加前や、キャバクラ3店舗に分岐する前の古い価格案を重ねて登録していません。
バック率は報酬プラン側の説明より商品ごとの最終値を優先し、二重加算を避けています。

ユーザー提供画面で確認した項目は、会計区分・表示カテゴリ・販売価格・原価・発注点、
率バック／指名別単価、本指名pt、キャストドリンク按分除外、料金・ランク・VIP設定などです。
スクリーンショットだけではAPI・DBスキーマ・集計ロジック・実装完了状況までは確認できません。

record_status の意味：

| 値の系統 | 意味 |
|---|---|
| proposed_master / proposed_rule / proposed_plan | 登録・設定の案 |
| specification_only | 実装確認前の仕様案 |
| validated_reference_arithmetic | このパッケージ内の明細計算を検証済み |
| unverified_target / ui_target | 会話で設定した目標値・表示案 |
| proposed_opening_snapshot | 元イベント全件がない開始残高案 |
| arithmetic_reference_only | 入力案を算術再計算した参考値 |

全月の伝票生成や、データベースへの投入を実行した事実はありません。
検証のPASSは上記の範囲を広げるものではありません。
