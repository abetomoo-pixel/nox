## 5〜7分版

### 1. ACEの営業画面

今日の出勤・卓・予約を表示します。確定売上と未会計見込みを別々に示してください。
ひなのの108,000円は現時点では表示目標です。実伝票からの確定売上ではありません。

### 2. 商品入力からバックへのつながり

モエ1本22,000円、バック20%を使います。単品バックは4,400円です。
1人に全額帰属するという前提の単独テストでは、売上108,000＋22,000＝130,000円。
3段階目の時給帯は4,500円です。ただし未会計中は見込みとし、実際の時給適用日は確認してください。
注文した瞬間に当日の確定給与が上がると説明しないでください。

### 3. 計算済み会計の例

ACEの `A0925-008` は小計154,000円、サービス30,800円、税18,480円、総額203,280円。
この伝票を複製した参考ケースにモエ1本を追加すると、税・サービス込みの増分は29,040円、総額232,320円です。
会話中に出た「会計220,000円」は使用しません。
本指名1,000円・同伴1,500円・商品25,500円で、伝票由来バックは28,000円です。
時給部分や月次ボーナスはこの金額に含めません。

### 4. 顧客と売掛

S様の開始残高84,000円を開きます。25,000円＋59,000円の2件が未決済です。
非計上テストで50,000円入金すると、古い25,000円を完済し、次の残が34,000円になります。
売掛は顧客の未収金として扱い、キャスト給与の控除にはつなげません。

あべ：Sランク・Premium、ゆい：Aランク・Standard。
お客様への指名料と、キャスト側の指名バックが別設定であることを示します。

## 報酬画面を見せる際の注意

9月分は参考計算と表示してください。全月の伝票・打刻、割増・控除の確定はできていません。
こころの9月実績は入店前なので対象外です。
新人保証はみおの9/15〜11/14、こころの10/1〜11/30の期間設定案を見せます。
自動終了・自動プラン変更は本体確認前に動作を約束しないでください。

## デモ終了・リセット

未確定の追加注文・テスト入金を本番会計として確定しないでください。
次回は専用デモ状態へ戻し、同じ売掛やバックが二重計上されていないことを確認します。
