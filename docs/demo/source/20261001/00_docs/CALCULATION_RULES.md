# 計算ルールと未確定事項

## 金額・端数

通貨はJPY。整数円で保持します。率はbasis pointsで、1,000＝10%、2,000＝20%です。
価格は税・サービス料加算前。税込相当と記載した初期案から、後半の基準へ整理しました。
原価も同じ基準の架空入力値です。実際の仕入額を調査・税抜変換したものではありません。

参照伝票は次の順に計算します。端数処理は各段階で1円未満切り捨てです。

```text
小計 = Σ(単価 × 数量)
サービス料 = floor(小計 × service_bps / 10000)
税額 = floor((小計 + サービス料) × tax_bps / 10000)
会計総額 = 小計 + サービス料 + 税額
```

ここでのtax_bpsはデモ計算パラメーターです。税務・給与の実運用に関する判定は行っていません。
売上合計は税込の会計総額、商品バックは税・サービス料加算前の商品金額を基準にします。
商品粗利率は `(売価 - 商品原価) / 売価`。キャストの基本報酬、家賃、手数料などは含みません。
バックを引いた残額も営業利益・店舗の最終利益とは呼びません。

## 料金

料金は伝票を開いた時点のスナップショットを参照します。
LUNAの20時台アーリーで開始した代表伝票では、延長30分もアーリーの2,500円を参照します。
金土のNOIR VIPは14,000円/60分・人、延長7,000円/30分・人。
金土のACEは8,000円/60分・人に、VIP利用時5,000円/60分・人を加えます。
ACEのVIP延長30分加算は未確定のためnullです。

本指名・場内・同伴の請求単位は参照伝票では1伝票・対象者あたり1回です。
指名料の延長時再請求、場内から本指名への昇格時処理は本体確認が必要です。
同伴に本指名を付ける場合も、本指名イベントを重複して作成しません。
営業時間の終了は未指定です。料金ルールの翌06:00は仮の照合境界で、営業時間を意味しません。
日曜店休等は料金ルールとは別に `september_business_calendar` を参照します。

## 商品バックと指名実績バック

商品バックは `product_master_only` として、報酬プラン側の固定名プリセットを追加加算しません。
NOIR Standard/Premium間の商品個別上書きは未確認のため、商品バック値を共通にします。
報酬プランによって変えるのは基本時給と指名・場内・同伴の実績バックです。

率方式：`floor(商品単価 × 数量 × back_rate_bps / 10000)`。
指名別固定方式：本指名・場内・同伴・フリーのうち1区分の単価だけを使います。
同伴＋本指名の代表例では商品バックに同伴単価を使い、2種類を重複加算しません。
別の指名実績バックは、本指名1回と同伴1回をそれぞれ計算します。

バック対象者が不明な場合、自動的に全員へ付与する設計にはしていません。
複数キャストで1商品を按分する規則は未確定です。6代表伝票では商品行ごとに受領者1名を指定しています。
「キャストドリンク（按分除外）」が本人の売上集計にもどう影響するかは、本体の集計仕様を確認してください。
本指名ptの値は保持しますが、一般的な購入ポイントとして自動付与したとは扱いません。

## 売上スライド・ボーナス・保証

ACEの基準は30,000→3,000円、70,000→3,500円、120,000→4,500円です。
それ未満は2,500円。境界値ちょうどを含みます。
ただし時給の適用日（翌日、次勤務、当日への遡及など）は未確定です。
画面には翌日以降への反映とあるため、注文した瞬間に当日給与が遡及変更されるとは説明しません。

月間ボーナスの参考モデルは、同一指標では最高到達段のみを支給します。
売上ボーナスと本指名ボーナスは別指標として合計します。
多段達成や本指名によるボーナスは、提示画面では準備中の項目があるため提案仕様のままです。

新人保証は時給プランと期間の案であり、最低月額保証とは別です。
保証終了後の自動プラン変更は確認していません。

## 在庫

ボトル・瓶など、1商品販売と1在庫単位が一致する商品だけ在庫連動を提案しています。
ショット・グラスは杯からボトルへの換算を確認できないため在庫連動OFF。
キープ商品は新規販売時に1本減算し、その後のキープ利用で再び1本減算しません。
在庫スナップショットは `期首 + 入荷案 - 販売案` の算術検証のみです。
入荷日や販売伝票全件は未作成です。10/1在庫アラートは9月末案の表示用繰越です。

## 売掛

売掛は顧客に対する開始残高とし、キャスト給与からの天引きには連動させません。
入金額は古い未決済明細から充当し、一部入金を許容します。
10/5の50,000円入金は非計上のテスト。10/1時点の残高を変えません。
会計を再生して売掛を起票する方式と、開始残高を投入する方式は併用しないでください。
