# NOX デモデータ一式

作成日：2026年10月1日 / バージョン：1.0 / 架空データ

## まず開くファイル

確認用は `NOX_demo_review.xlsx`、開発用の一括データは `nox_demo_all.json` です。
店舗単位で使う場合は `07_by_store/` 内のJSONを参照してください。
各データは種類別のCSVとJSONでも収録しています。CSVはExcelで開きやすいUTF-8 BOM付きです。

## データの完成度を分けています

**01_master** は、この会話の最後の一覧を優先して整理した登録案です。
商品価格と原価は、後半で採用した「税・サービス料加算前」の架空入力値に統一しています。

**03_reference_receipts** は、明細が揃う6伝票をこのパッケージの参照計算で検算したものです。
NOX本体を操作して検証した結果ではありません。

**02_september_targets / 05_live_targets** は、会話で作成した集計・画面表示の案です。
全月の伝票・打刻から積み上がった確定実績ではありません。欠けている明細を捏造して追加していません。

## 重要な修正と保留

こころは2026/10/1入店のため、9月の勤務・報酬案を有効な9月参考合計から除外しました。
さくらのNOIR Premium売上ボーナスは、提示されたプランに従う参考計算では40,000円ではなく30,000円です。
NOIRのシャンパン商品別数量は108本で、途中にあった94本という説明とは一致しません。

このため、接客38名の原案総支給13,897,300円を「確定給与」として採用していません。
参考モデルを再計算し、入店前の1名を除いた合計は **13,648,300円** です。
この数値も未検証の月次入力からの参考値で、深夜等の割増、税、保険、控除などを反映した確定給与ではありません。

9月の店舗売上案43,740,000円は日次案の合計と一致します。ただし、全月の注文明細による裏付けは未作成です。

## 本体への取り込みについて

本パッケージは中間形式です。実際のNOXのDBスキーマ・APIは提供されていないため、直接投入用SQLは含めていません。
`00_docs/IMPORT_GUIDE.md` を読み、店舗IDや各フィールドを実テーブルに対応づけてください。
本番データへの投入・実際の給与支払には使用しないでください。

## 再検証

Python 3.10以降で、展開したフォルダ内から実行できます。外部ライブラリや通信は不要です。

```bash
python 06_validation/validate.py
```

検証成功は「本パッケージ内の参照計算・ID・合計の一致」を意味します。
NOXへの接続試験や未完成データの正しさまで保証するものではありません。
