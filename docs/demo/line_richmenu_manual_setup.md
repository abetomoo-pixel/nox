## 0. この手順で出来ること・出来ないこと（隠さない）

| | 今の作りで |
|---|---|
| 3 つのボタン（シフト／お知らせ／ホーム）を LINE のトークの下に出す | 出来る（店の LINE 公式アカウントの管理画面で） |
| キャストが押すと、ログインし直さずに NOX に着く | 出来る（LIFF の URL を使い、キャストが招待から LINE をつないでいるとき） |
| ボタンごとに違う画面に着く（シフト → 希望の画面 など） | **今は出来ない**。LIFF の橋が行き先を 1 つ（`/mine`）に固定している（`app/liff/[storeId]/liff-bridge.tsx:58`）。3 つとも `/mine`（ホーム）に着く。橋に `to` の許可表を足す変更（client の小さな直し）が入れば、登録し直さずにボタンごとの画面に着く＝下の URL は先にその形で入れておく |
| キャストだけに出す | **出来ない**。管理画面の登録は友だち全員に出る（スタッフ・お客様が友だちにいれば出る）。キャストだけにするのは API の案 1 だけ |
| 押された数を NOX で見る | 出来ない（LINE の管理画面の統計だけ） |

## 2. 3 つのボタンに入れる URL

`<liffId>` は店の LIFF ID（NOX の 店舗設定 › LINE 連携 に出ている値＝`stores.line_config.liff_id`）。

| ボタン | URL | 今着く所 | 橋の直しの後に着く所 |
|---|---|---|---|
| 左：シフト | `https://liff.line.me/<liffId>?to=shift` | `/mine` | `/mine/wishes`（希望の提出・今日以降のシフト） |
| 中：お知らせ | `https://liff.line.me/<liffId>?to=notices` | `/mine` | `/mine/notices` |
| 右：ホーム | `https://liff.line.me/<liffId>?to=home` | `/mine` | `/mine` |

- `https://noxapp.jp/mine/...` を直に入れない：LINE の中のブラウザに NOX の cookie が無いと `/login`（パスワード）に飛ぶ（`lib/supabase/middleware.ts:58-64`）。
- `/liff/<storeId>/shift` のように path に載せない（404）。

## 3. 押せる範囲の分け方

- 管理画面のテンプレ「小・横 3 分割」を選ぶ（3 つの幅は 833／834／833 px）。画像の 3 つの枠と同じ位置になる。
- 管理画面のテンプレは高さいっぱいで分かれる＝下のロゴの帯も、その上のボタンの一部として押せる（害は無い）。帯を押せなくするのは API の案 1 だけ（`docs/demo/richmenu/areas_2500x843.json`＝高さ 700 まで）。

## 4. 店が LINE の管理画面でやる操作（順に）

1. LINE Official Account Manager（`manager.line.biz`）に、店の公式アカウントの管理者でログインする。
2. 左のメニューで「トークルーム管理」→「リッチメニュー」→「作成」。
3. 表示設定：タイトル（例「NOX キャスト」・友だちには見えない）／表示期間（開始は今日・終わりは十分先）。
4. コンテンツ設定：「テンプレートを選択」→ 小さいサイズの横 3 分割 →「画像を作成」ではなく「画像をアップロード」で `nox_cast_richmenu_2500x843.png`。
5. A・B・C の 3 つのアクションに「リンク」を選び、上の §2 の URL を左から順に入れる。アクションのラベル（読み上げ用）はそれぞれ「シフト」「お知らせ」「ホーム」。
6. メニューバーの設定：テキスト（14 字まで・例「メニュー」）／メニューのデフォルト表示「表示する」。
7. 「保存」。キャストの LINE（自分の端末で友だちになっている人）で、トークの下にメニューが出ることを確かめる。
- 画面の名前・並びは LINE 側で変わることがある（この手順は 2026-11-13 時点の読み・画面では未確認）。

## 5. キャストが押したときに、ログインし直さずに着くための前提

1. 店の LINE 連携が済んでいる（店舗設定 › LINE 連携：Messaging API と LINE ログインの 2 チャネル・LIFF＝Full・openid・エンドポイント `https://noxapp.jp/liff/<storeId>`・Webhook ON・応答メッセージ OFF＝`docs/demo/line_first_run.md`）。
2. そのキャストが、NOX の招待（キャストの LINE 連携の案内）から LINE をつないでいる（`line_links` に行がある）。つないでいない LINE で押すと「招待から開いてください」（`app/api/line/session`→ 404 not linked・`liff-bridge.tsx:21`）。
3. 流れ＝LIFF が LINE の id_token を NOX に渡す → NOX が確かめて Supabase のセッションを作る（メールは送らない・`lib/nox/line/server.ts:51-62`）→ キャストは `/mine`。
- **未確認**：LIFF とアプリ内ブラウザが同じ cookie を使うか（実機で）。

## 6. スタッフが押したとき

- スタッフ・店長が LINE をつないでいれば、LIFF 経由で `/dashboard`（店側のホーム）に着く（`lib/nox/line/subject.ts:24`）。お知らせやシフトの画面ではない。
- つないでいなければ「招待から開いてください」。
- お客様が友だちにいる店では、お客様にもメニューが見え、押すと同じ案内になる（NOX の中身は見えない）。キャストだけに出したい店は、案 1（API）の判断待ち。
