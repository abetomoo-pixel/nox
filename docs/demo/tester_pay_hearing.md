# お店の報酬の決まりについての聞き取り（テスターのお店向け・1 枚）

2026-11-19 夜　作成（CC 起草・相談役の指示 ⑤）。根拠＝外部のレビューとの突き合わせ（docs/tmp/review_gap_1118.md）とホストのデモの「未対応の機能」（docs/demo/host_unsupported_1118.md）。

## この紙の使い方

- お店の方に、上から順に聞いて「お店の答え」の欄に書きます。分からないところは空けたままで大丈夫です。
- 右の欄は、NOX で今どう扱えるかです。
  - **そのまま入る**：設定の画面で、そのまま入れられます。
  - **工夫すれば入る**：少し置き方を変えれば同じ結果になります（例：別の名前の項目として入れる）。
  - **今は入らない**：今の NOX では表せません。お店にはそのまま正直に伝えます。
- 「今は入らない」のときに使う言い方を、各項目の最後に書いています。「いつ対応します」とは言いません（「今はありません」「準備しています」までにとどめます）。

## 1. 時給

| 聞くこと | お店の答え | NOX で | 入らないとき・工夫するときの伝え方 |
|---|---|---|---|
| 基本の時給はいくらですか。人によって違いますか。 |  | そのまま入る | — |
| 体験入店の時給は別ですか。 |  | そのまま入る | — |
| 時間帯（例：0 時以降）で時給が変わりますか。 |  | 今は入らない | 「時間帯ごとに時給を変える設定は今はありません。いちばん長い時間帯の時給で始めて、差は個別の加算で合わせます」 |
| 売上や指名の数で時給が上がりますか（スライド）。 | （→ 5. スライド） |  |  |

## 2. 指名と同伴のバック

| 聞くこと | お店の答え | NOX で | 入らないとき・工夫するときの伝え方 |
|---|---|---|---|
| 本指名のバックは 1 組いくら、または売上の何％ですか。 |  | そのまま入る | — |
| 場内指名のバックは。 |  | そのまま入る | — |
| 同伴のバックは。 |  | そのまま入る | — |
| 指名が複数のとき、売上をどう分けますか（人数で等分・決めた割合など）。 |  | そのまま入る | — |

|---|---|---|---|
| 売上の何％を歩合として払いますか。 |  | そのまま入る | — |

## 聞き取りのあとに

- 「今は入らない」が付いた項目は、お店の答えと一緒に相談役へ渡します（どの項目が何店で要るかを数えるため）。
- 「工夫すれば入る」は、置き方を店長と一緒に決めて、最初の締めの明細をお店の計算と並べて確かめます（差が出たら、その行と理由を記録）。
