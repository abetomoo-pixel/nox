# デモ環境 対応表（NOX_demo_data_20261001 → NOX）

便 D0-2（裁定328・2026-10-01）。出典＝docs/demo/source/20261001/nox_demo_all.json（51 dataset・validate.py PASS）。
NOX 側の表・列・RPC は supabase/migrations 0001〜0161 の定義から取った（live 読取なし・DB 恒久変更 0）。
採用＝生成器（便 D1）が投入する／保留＝今回は投入しない（理由を右欄に）。**投入経路は裁定276-1「録画再生」**＝生成器が実 RPC で作って閉じた行を録り、`demo_org_reset` の payload として再生する。マスタ（store／casts／products 等）は seed:demo と同型の service 直 INSERT を録画に含める。

### 0.1 先月相当の写像

リセット日の営業日を R（例 2026-10-01）とすると、先月 M = R の前月。パッケージの 2026-09-dd（dd ≤ 30）は M-dd に写す。M が 31 日ある月は dd=31 が空く（売上 0 の日＝生成器が「特別店休」と同じ扱い）。M が 28／29 日の月（2 月）は dd=29／30 を切り捨てる＝月次合計が golden から外れるため、**生成器は M の日数で日次目標を再配分**し golden は「月次売上 43,740,000 ±（切り捨て日の目標額）」ではなく「配分後の Σ＝stated_monthly_gross」で突合する（gen_plan.md §3）。
曜日は写像で崩れる（9/18 金 → 10/18 日）。pricing_rules の曜日別料金（金土）と `september_business_calendar` の日曜定休は**写像先の実曜日**で引き直す＝gen_plan.md §2。
