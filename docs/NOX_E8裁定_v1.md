### 4-1. M7 の切り分け結果 ＝ **バグではなく仕様の防御**（UI の説明欠落）

- 原因の連鎖: **CLUB NOX の在籍キャスト7名は全員 `casts.user_id` が null（＝未招待）**
  → `memberships`（role='cast'）が0行 → ページ側で `membershipId` が null
  （`app/(manage)/master/cast-comp/register/page.tsx:28-33`）
  → チェックボックスが `disabled={busy || !r.membershipId}`
  （`app/(manage)/master/cast-register-panel.tsx:103`）で**恒久 disabled**＝押しても無反応。
- 実機確認（demo-manager・store フラグ「有効」）: **7行すべて `disabled: true`**・
  出ている注記は「切替は owner のみ」の1本のみで、**押せない理由の表示はゼロ**。
- 判定: `can_register` は membership の列なので、membership が無ければ書く先が無い＝**防御は正しい**。
  欠けているのは UI の説明。**E8-1 で「未招待（先に /casts で招待）」バッジ＋導線を出せば解消**
  （app のみ・[A] 相当・DB 改稿不要）。

### 4-2. staff#5「端末の最終アクセス・IP・オンライン状態」の DDL 確認結果（判定材料）

- `kiosk_devices` の実列 = id / org_id / store_id / auth_user_id / label / is_active /
  created_at / updated_at / purpose ＝**last_seen 系の列は無い**。
- ただし `kiosk_sessions` に **`last_seen_at` が存在**（実データ3行・最新 2026-07-31）。
  → **レジ端末（purpose='register'）のみ「最終アクセス」を近似表示できる**（[B]）。
- **打刻端末（purpose='punch'）は不可**: セッションを持たず、`punches` にも device 参照が無い
  （列 = id/org_id/store_id/cast_id/punched_at/type/lat/lng/ip/within_geofence/source/note/created_at）。
- **IP・オンライン状態は保持なし＝[C]**（punches.ip はキャストの打刻 IP であって端末の常時 IP ではない）。
- → 提案: **「レジ端末の最終操作」だけ [B] で採用・打刻端末とIP/オンラインは対象外**が妥当。**要裁定**。
