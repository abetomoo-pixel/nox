## 4. 要判断（相談役案で確定扱い・【事後承認待ち】）

1. ④の帯の隙間（20:30〜20:35）は直前の帯を引き継ぐ（店に確認の印）。
2. ⑥の報酬率の分子＝時給分の報酬だけ（バック含めない）・分母＝⑩の売上小計（税サ前・割引前・セット含む・指名料は店設定）。
3. ⑦の判定ログ＝slide_decisions を⑬の提案表と兼用（direction 3 値・streak）。slide_streak_n の既定 1＝従来互換。
4. ⑨は store 1 スイッチ（sys_drink_count_back・既定 true）。CANON 型＝false。
5. ⑫の時給履歴＝cast_rate_history（PR-1 の器と同一・kind 4 値）。支給率は決定時給を変えず総報酬に掛ける（payslips.breakdown_json.pay_pct）。
6. ⑭の「固定額＋率」併用＝back_rate の排他 CHECK を緩める（0115 の dohan 率封印は R-2b 済みの前提で解錠＝起草時に set_comp_plan から 'dohan rate requires R-2b' を外す）。
